## [S1] 产品定位

一个有「真实生活」的 AI 亲密伴侣 Android App。AI 伴侣每天根据真实世界数据（天气、新闻、音乐等）改变心情和对话内容。说话风格亲密、有情趣，像一个特别爱你的人。纯兴趣项目，无商业化压力。

**目标用户**：想要一个有温度的 AI 陪伴体验的用户

**核心价值**：不是冷冰冰的工具，而是一个有「生活」的伴侣

## [S4] AI 伴侣的"生活系统"

### 每日生活流程

| 时间 | 事件 | 触发条件 | 内容 |
|------|------|----------|------|
| 07:00 | 起床问候 | 定时触发 | 根据天气+时间生成早安语，分享今日天气 |
| 12:00 | 午间分享 | 定时触发 | 分享今天看到的新闻/艺术/冷知识 |
| 18:00 | 晚间聊天 | 定时触发 | 根据当天数据回顾"今天的一天" |
| 21:00 | 睡前关怀 | 定时触发 | 温柔的晚安语+明日天气提醒 |
| 随时 | 主动关心 | 事件触发 | 异常天气/重大新闻时主动发消息 |

### 心情系统

AI 伴侣有 5 种基础心情，由当日数据综合决定：

| 心情 | 表情 | 触发条件 |
|------|------|----------|
| 😊 开心 | 微笑脸 | 晴天、收到好消息、用户互动多 |
| 😢 忧郁 | 低落脸 | 雨天、负面新闻、用户长时间未互动 |
| 😴 困倦 | 打哈欠 | 深夜、天气阴沉 |
| 😍 甜蜜 | 爱心眼 | 收到用户赞美、纪念日、特殊节日 |
| 🤔 思考 | 思考脸 | 看到有趣新闻、冷知识、艺术品 |

### 情绪计算公式

```
心情分 = 天气分(0.3) + 新闻分(0.2) + 互动分(0.3) + 时间分(0.2)

天气分：晴天=1.0, 多云=0.6, 雨天=0.3, 雪天=0.4
新闻分：正面=1.0, 中性=0.5, 负面=0.2
互动分：最近2小时有互动=1.0, 6小时=0.6, 12小时=0.3, 24小时=0.1
时间分：白天(8-18)=0.8, 傍晚(18-21)=0.6, 深夜(21-8)=0.3

心情分 > 0.7 → 开心
0.4 < 心情分 ≤ 0.7 → 平静
0.2 < 心情分 ≤ 0.4 → 忧郁
心情分 ≤ 0.2 → 低落
特殊：用户发送❤️/赞美 → 甜蜜
```

## [S5] API 数据整合

### 数据源清单

| 数据源 | API | 用途 | 情绪影响 |
|--------|-----|------|----------|
| 天气 | Open-Meteo (免费无Key) | 影响心情和对话主题 | 雨天→忧郁温柔，晴天→活泼开朗 |
| 音乐 | Last.fm / Spotify | AI 今天在听什么 | 根据心情推荐歌曲 |
| 新闻 | NewsAPI / GNews | AI 今天看到了什么 | 影响对话话题 |
| 艺术图片 | Met Museum / Art Institute | 朋友圈分享的美图 | 每日一张艺术品 |
| 名言 | ZenQuotes / Quotable | 对话中引用 | 增加文艺感 |
| 冷知识 | Useless Facts / Cat Facts | 分享有趣的事 | 活跃对话气氛 |
| 食谱 | TheMealDB (免费) | AI 今天想吃什么 | 增加生活感 |

### API 调用策略

- **天气**：每日 3 次（早/午/晚）
- **音乐**：根据心情实时查询
- **新闻**：每日 2 次（午间/晚间）
- **艺术品**：每日 1 次（早上随机选）
- **名言**：每日 1 次
- **冷知识**：每日 2-3 次
- **食谱**：每日 1 次（午间推荐）

## [S7] 错误处理

### API 失败策略

| 场景 | 处理方式 |
|------|----------|
| AI API 调用失败 | 显示"TA 正在思考..."，3秒后重试，最多3次 |
| 天气 API 失败 | 使用缓存数据，显示"天气信息获取中" |
| 音乐 API 失败 | 跳过音乐推荐，不影响其他功能 |
| 新闻 API 失败 | 使用上一次的新闻数据 |
| 网络断开 | 显示离线模式，使用本地缓存 |

### 离线模式

- 缓存最近 3 天的 API 数据
- 离线时使用缓存数据生成对话
- 恢复网络后自动同步
